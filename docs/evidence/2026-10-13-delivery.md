Kontrollene er utført av Codex på Runes bestilling. De gjelder den lokale caseimplementasjonen og de lenkede GitHub-kjøringene, ikke produksjonsgodkjenning eller full lukking av KR-er.

Amedias historikk er bevart. PR-ene er åpne for gjennomgang; de er ikke merget til master. Ingen artikkeldata, personlige Sitter-analyser eller hemmeligheter er lagt til i leveransen.

## Ren lokal kopi

En separat kopi av commit 998a285 ble laget med git archive, uten eksisterende node_modules eller config/local.json. På Node 24.21.0 installerte npm ci 124 pakker, og npm test ga12 beståtte tester. npm start startet serveren, og SIGINT stoppet den.

Serverens oppstart og lokale ruter ble kontrollert på port 8099 for å unngå å stoppe Runes server på 8080: preview, manifest, avisvelger og CSS svarte 200; ugyldig count svarte 400. Dette er oppstarts-/HTTP-kontroll, ikke en full nettlesertest fra den rene kopien: include-adressene er fortsatt hardkodet til 8080. Ved vanlig preview brukes 8080 som README beskriver. Den fullstendige visuelle kontrollen ligger i [layoutbeviset](2026-10-12-layout.md).

## Uavhengig teknisk review

IRIS Code Reviewer i separat instans /root/review_delivery ga teknisk PASS for API-uttrekk/routerkontrakt og CI-konfigurasjon. Reviewer skrev ingen implementasjon og kjørte egne 12 tester på Node 24.21.0. Ekstra midlertidige HTTP-kontroller bekreftet valgt avis, count=2, riktig artikkeldomene, HTML-escaping og avvisning av ugyldig count uten API-kall.

Reviewgrunnlaget var et låst lokalt filøyeblikksbilde over base a168c1. Basecommitens komponentrute var en plassholder; eksakt ekvivalens med den mellomliggende inline-implementasjonen kunne derfor ikke bevises. Verdictet gjelder den endelige kontrakten. Runes fulle gjennomgang av uttrekk og CI gjenstår; dette hevdes ikke bestått.

Øvrige: body-parser,brace-expansion,compression,fast-copy,minimatch,path-to-regexp og qs. Versjonene er ikke oppdatert i denne leveransen. Rettelser må testes for kompatibilitet før prosjektet publiseres som kjørende tjeneste. Grønne funksjonstester eller CI betyr ikke at avhengighetene er sikkerhetsgodkjent.
